# DM 公告

> 编辑此文件直接修改弹窗内容。每个 `## 标题 [kind] [lang]` 是一个分区，
> kind 决定渲染样式：
>   - `[warn]` 红色警告条 / `[info]` 蓝色提示条
>   - **A 板块** `[issues]` bug / 需求表格 — 每行 `类型 | 严重度 | 描述`，
>     类型 ∈ `bug` / `feature` / `wip` / `done`；严重度 ∈ `critical` /
>     `high` / `medium` / `low`（可省略）。
>   - **B 板块** `[highlights]` 新亮点图文 — 每行 `图片URL | 标题 | 描述`，
>     图片可省（仅写 `标题 | 描述` 也行）。图片相对路径会自动按 base 解析。
>   - **C 板块** `[changelog]` 简单更新日志 — 每行 `版本号 · 描述`。
>   - `[todo]` 普通待办列表（每行 `desc | tag | size`）/ `[footer]` 落款。
> lang 控制独立的 CN|EN 切换：`[zh]` 仅中文模式显示，`[en]` 仅英文，
> 不带语言标签则两边都显示（如 footer / 共享通知）。
>
> 行内：`**粗体**`、`` `代码` ``、邮箱自动转 mailto 链接，
> `<span style="color:#hex">文本</span>` 给一段文字上色。

## Full Suite 插件项目封盘公告 [warn] [zh]

感谢各位 DM、玩家这一个月以来的支持...！

很难想象啊一个月时间都不到就有了如此翻天覆地的变化。

这一路走来，每一次反馈、每一笔赞助、每一次在群里向朋友推荐我都牢记于心。本来我只是自己粗糙的使用，想要让我带团更方便而做的，但已经发展成了这样一个夸张的状态。

受限于 Owlbear Rodeo 本身的能力边界，加上个人精力实在有限，我决定不再投入新的开发和维护工作。**已上线的所有功能将保持现状继续运行**，但可能不会再有新版本、新功能、新修复了。

──

**【关于代码与二次使用】**

项目代码已全部开源（仓库地址可在插件「<span style="color:#5dade2">设置 → 支持</span>」标签里找到）。如果你有继续使用、定制或二次开发的需求，可以参考以下说明：

- ✦ 自由下载、自行部署、按需修改 —— 完全没问题。
- ✦ <b>私用 / 桌团自用 / 不对外发布</b>的任何修改：<span style="color:#5dade2">完全自由，不受任何限制，按你的意愿来就好</span>。
- ✦ 任何形式的<b>"对外发布"</b>（公开仓库、对外分发、上架、第三方传播等）：请保留作者署名（<b>FullPeople</b>）与项目 icon，<span style="color:#f5a623">禁止任何形式的商业用途</span>。具体条款请以仓库内的开源协议为准。

──

**【插件内嵌音乐板下线说明】**

随项目封盘，插件内嵌的音乐板（侧栏图标 + 配对弹窗 + 后台音频引擎）已停止维护并下线。独立的网页版音乐板继续可用：

<span style="color:#5dade2">**https://obr-suite-custom.pages.dev/studio/music-studio/**</span>

它现在作为一个普通的网页播放器使用，可以整理 BGM/SFX 曲库、本地试听、开语音时共享电脑音频给玩家。原有"配对枭熊让所有玩家同步播放"的能力不再可用；如果需要这个能力，请自行下载源码部署。

这段路能陪你们走过来，是这个项目最大的意义。
说不定哪天我又突然蹦出来做点什么呢，谁知道呢，总之非常感谢啊非常感谢。

## Full Suite Project Closure [warn] [en]

Thank you, every DM and every player, for the support over this past month...!

It's honestly hard to believe how much has changed in less than a single month.

Every piece of feedback, every contribution, every word-of-mouth recommendation in a group chat — I've taken all of it to heart. This started out as something rough I patched together just to make running my own games easier, and somehow it's grown into this whole exaggerated thing.

Limited by what Owlbear Rodeo's plugin surface lets me build, and by my own bandwidth, I've decided not to put any more time into new development or maintenance. **Everything currently live will keep running as-is**, but there probably won't be any new versions, new features, or new fixes.

──

**About the code & reuse**

The full source code is open-sourced (repo link in <span style="color:#5dade2">**Settings → Support**</span>). If you'd like to keep using it, customise it, or build on it:

- ✦ Download, self-host, modify freely — go ahead.
- ✦ <b>Private / personal-table / not-publicly-released</b> modifications of any kind: <span style="color:#5dade2">fully unrestricted, do as you wish</span>.
- ✦ Any form of <b>"public release"</b> (public repos, redistribution, listing, third-party hosting, etc.): please keep the author credit (<b>FullPeople</b>) and the project icon, and <span style="color:#f5a623">no commercial use of any kind</span>. The in-repo license is the binding word.

──

**In-plugin music board retirement**

With the project closure, the in-plugin music board (sidebar tool + pairing popover + background audio engine) is no longer maintained and has been taken down. The standalone web version is still available:

<span style="color:#5dade2">**https://obr-suite-custom.pages.dev/studio/music-studio/**</span>

It works now as a regular browser-side player — organize BGM/SFX, preview locally, share your computer audio over voice chat. The "pair-with-plugin so all players hear sync'd audio" feature is no longer available; if you need it, self-host from the source.

──

That you came this far with me is what this project meant the most.
Who knows — maybe one day I'll just suddenly pop back up and make something again. Either way, truly, truly thank you.
